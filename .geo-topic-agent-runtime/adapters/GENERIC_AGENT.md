# Generic Agent Adapter

Use root `AGENT.md` only as a bootstrap. Canonical package root is `.geo-topic-agent-runtime/`; read its `AGENTS.md`, contract, skills, and references.

Use `python .geo-topic-agent-runtime/geo_agent_cli.py <command>`. First setup uses `--runtime generic`.

Do not depend on `PYTHONPATH`. Preserve context/audit separation, confirmed brand variants, post-audit topic intake, exact live paid scope, and dashboard knowledge-only behavior.


## Runtime Adaptation Review

The first `setup` command only detects the runtime and writes a plan with `plan_hash`. Review that plan first. A separate apply command must include both `--apply-runtime-adaptation` and the exact `--reviewed-runtime-plan-hash <plan_hash>`; otherwise no adaptation is applied.
