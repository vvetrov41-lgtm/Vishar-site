# Today opening performance

Opening Today must render its self-contained server pulse independently of schedule, enquiries, conversations, email, names and activity. The named schedule must render independently of pulse. Returning from another CRM route must show the previous authorized snapshot immediately while fresh data loads. Never report attention as clear before either authoritative pulse or the complete browser fallback is available.

Preserve confirmed/proposed appointment rules, booking evidence, acknowledgement precedence, priorities, filters, artist/workspace isolation, authorization and fallback. Cache stays bounded in memory, scoped to authenticated API/profile/capabilities/artist/day, expires on later entry and clears on auth changes. Timing telemetry contains fixed stages and bounded numbers only.

Acceptance requires exact production SHA readback on both CRM hosts, production SQL measurements and actual browser content timing when an authenticated reachable surface or telemetry is available. CI alone is insufficient.
