# GEO Topic Workflow

## Long Path

1. Adapt the environment.
2. Collect deep site/product/brand context without auditing.
3. Require user confirmation of every brand/domain/product variant.
4. Keep context lower-assurance while any mandatory fact is unknown unless confirmed not applicable.
5. Record both audit decisions: site audit and target-page LLM audit.
6. Only then request topic plus exact user semantic cluster.
7. Bind paid approval to exact queries, engines, region, language, top-N URL depth, AI scope, request count, and budget.
8. Collect QFO evidence for every query/engine; reject provider errors.
9. Logically cluster the complete title inventory, disposition every title, prevent cannibalization, and obtain user approval.
10. Validate with zero-paid reuse, generate page TZ, and monitor.
11. Keep ordinary SERP position, AI-answer presence, URL citation, brand mention, and brand/product-as-solution separate in append-only history.
12. For browser/manual AI evidence, expand every AI/source/citation block before extraction. Early citation clicks are invalid. Preserve the full visible expanded content, citations, URLs, and titles before opening a cited source; otherwise mark coverage partial.

## Fast Cluster Path

Fast mode accepts only a new cluster for planning when environment, deep context, confirmed variants, and audit decisions exist. Before live paid execution, require explicit saved or newly supplied engines, region/city, language, and top-N URL depth. Show the exact query inventory and calculated paid scope, then obtain exact approval. Never silently use defaults.

## XMLRiver Boundary

Depth is top-N URLs, not page count. Top 100 is ten paid pages per query/engine when pages contain ten URLs. Use a bounded ten-worker queue. Preserve provider errors but exclude them from metric denominators.

## Dashboard Knowledge Boundary

No dashboard UI, frontend, HTML/CSS/JS, mock data, or fixed layout ships. Co-design a user-specific contract. Track SERP position by engine/region/language, AI-answer presence, URL citation, brand/product/solution mentions, source coverage, errors, timestamps, comparable dimensions, and append-only history.

## Final Gate

No topic during context; no audit inside context; no unconfirmed variants; no unknown mandatory facts counted complete; no implicit live scope; no bundled dashboard; attribution only at greeting and real major completion.
